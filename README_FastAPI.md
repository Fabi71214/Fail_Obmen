# Файлообменник на FastAPI

## Изменения от Flask к FastAPI

Проект был успешно переведен с Flask на FastAPI. Все основные функции сохранены:

### Что изменилось:

1. **Основной файл**: `app.py` (Flask) → `main.py` (FastAPI)
2. **Зависимости**: Обновлены в `requirements.txt`
3. **Шаблоны**: Минимальные изменения (убран `url_for` для статики)
4. **JavaScript**: Остался без изменений - все работает как раньше

### Преимущества FastAPI:

- ✅ Более высокая производительность
- ✅ Асинхронная обработка запросов
- ✅ Автоматическая документация API (доступна на `/docs`)
- ✅ Современный подход к разработке

## Установка и запуск

### 1. Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 2. Запуск сервера:

```bash
python main.py
```

или с помощью uvicorn напрямую:

```bash
uvicorn main:app --host 0.0.0.0 --port 6767 --reload
```

### 3. Открыть в браузере:

```
http://localhost:6767
```

## Доступные эндпоинты:

- `GET /` - Страница входа
- `POST /login` - Авторизация (пароль: 8962)
- `GET /success` - Список папок
- `POST /upload` - Создание новой папки
- `GET /folder/{folder_name}` - Просмотр содержимого папки
- `POST /upload_file/{folder_name}` - Загрузка файла в папку
- `GET /download/{folder_name}/{filename}` - Скачивание файла
- `GET /delete/{folder_name}/{filename}` - Удаление файла
- `GET /delete_papk/{folder_name}` - Удаление папки
- `GET /docs` - Автоматическая документация API (новое!)

## Совместимость:

Все HTML-шаблоны и JavaScript код работают точно так же, как и в Flask версии. Не требуется никаких изменений на клиентской стороне.
